# 绮梦短剧 shorttv.online py 源（2026-08-24 新写）——Next.js SPA + JSON API + 付费墙 范本

站点：https://shorttv.online/（绮梦短剧，成人短剧站，Next.js SPA）。成品 `templates/shorttv.py`。
**这类站（Next.js/React SPA，页面内容全靠 fetch JSON）不要解析 HTML，直接挖 API**——本文件是完整挖 API 流程。

## 0. SPA 站点 API 发现流程（通用）

1. `curl 首页` → 页面 HTML 只有导航壳 + `正在加载…`，内容全靠 JS → **不是解析 HTML 的路子**
2. 抓首页所有 `<script src="/_next/static/chunks/*.js">`（Next.js 特征）→ 逐个 GET，正则 `api/v3/public/[a-z0-9/_{}$.-]+` 收集全部 API 路径（本站在 30 个 chunk 里挖出 30+ 端点）
3. **API base 域名 ≠ 站点域名**：`const api=(path)=>(base||location.origin)+path; const base="https://production.nodenear.shorttv.online"` ——`webpc/home` 在 `shorttv.online` 上 403、在 `production.nodenear.shorttv.online` 上 200。**发现 api 函数定义后看它的 base 变量**
4. 请求带上 `Referer: https://shorttv.online/`（部分端点校验）

## 1. 核心 API 端点（实测）

| 端点 | 用途 | 关键字段 |
|------|------|---------|
| `GET /api/v3/public/webpc/home` | 首页 | `data.hot[18]` + `data.updates[12]`（剧列表） |
| `GET /api/v3/public/theater/groups` | 分类组 | `data.latest/hot/top_rated` |
| `GET /api/v3/public/theater/dramas?genre={slug}&limit=30` | 分类列表 | `data.items[]` + `data.next_cursor`（**游标翻页**） |
| `GET /api/v3/public/rankings/{key}/dramas?limit=50&offset=N` | 榜单（follow/hot/new） | `data[]` 直接是 list，**offset 翻页** |
| `GET /api/v3/public/search?q={wd}&limit=36` | 搜索 | `data[]` 直接是 list |
| `GET /api/v3/public/dramas/{id}` | 剧详情 | `data.episodes[]`（index/title/media_asset_id/is_free/locked）+ `free_episodes` + `sensitivity` |
| `GET /api/v3/me/dramas/{id}/episodes/{index}/playback` | **播放** | `data.episode.playback_url`（mp4 或 keyserver m3u8）+ `episodes[]`（全部集含 locked 标记） |
| `GET /api/v3/public/feed/initial` | 首页 feed | **单条 item + continuation_cursor**（feed 流模式，不适合做列表源） |
| `GET /api/v3/me/adult-confirmations` POST | 成人确认 | 401（需登录，游客拿不到） |

## 2. ⚠️ 三大坑（都踩过）

### ① limit 超限返回 422 validation failed（不是 400/403）
`theater/dramas?limit=36` → **422** `{"status":false,"message":"validation failed"}`。实测：theater/dramas limit 上限 **30**；rankings 可到 **50**。**不同端点 limit 上限不同，逐一试探**（20→30→36→50 递增），422 = limit 超限不是 URL 写错。

### ② theater/dramas 用 cursor 翻页，`page` 参数无效
`?page=2` 返回和 page=1 **完全相同**的首条（参数被忽略）→ 必须用 `next_cursor`：先请求拿 `next_cursor` → 再 `&cursor={cur}` 翻页。实现：
```python
if page > 1:
    cur = ''
    for _ in range(page - 1):
        j = self._req_json(url + (f'&cursor={cur}' if cur else ''))
        if not j or not j.get('data'):
            break
        cur = j['data'].get('next_cursor', '')
        if not cur:
            break
    if cur:
        url = f'{BASE}/api/v3/public/theater/dramas?genre={tid}&limit=30&cursor={cur}'
```
rankings 反而用 offset 翻页（`?limit=50&offset={(page-1)*50}`）——**同一站点两种翻页机制并存，按端点区分**。

### ③ 付费墙：locked 集没有 playback_url；SENSITIVE 剧要成人确认
- `playback` 响应里 `episode.locked=True` 的集 → **无 playback_url 字段**（要充值解锁）→ detailContent 里 `if ep.get('locked'): continue` 跳过，不要塞空线路
- `free_episodes=9999` = 全免费；`free_episodes=N` = 前 N 集免费（试看），第 N+1 集起 locked
- `sensitivity=SENSITIVE` 的剧（如淫魔重生之情欲江山）`requires_adult_confirm: true` → 游客请求 playback 返回的 episode **连免费集也没有 playback_url**（`?adult_confirm=true` 等参数无效，`POST adult-confirmations` 401 需登录）→ **这类剧在羊壳里播不了，直接跳过该集即可，不要当 bug 修**
- 普通剧（sensitivity=NORMAL）免费集一定返回 playback_url（external-mp4 直链或 keyserver m3u8 签名链接，签名过期时间 `playback_expires_at`，约 20 分钟）

## 3. 详情播放链路（付费墙处理后的最终形态）

```python
# detailContent: 只对未 locked 的集请求 playback 接口（每集 ~1s，9 集 9s 可接受；更快的做法是只请求免费集）
for ep in (d.get('episodes') or []):
    if ep.get('locked'):
        continue
    pj = self._req_json(f'{BASE}/api/v3/me/dramas/{vid}/episodes/{idx}/playback', timeout=6)
    if pj and pj.get('data') and pj['data'].get('episode', {}).get('playback_url'):
        play_urls.append(f"{ep_title}${pj['data']['episode']['playback_url']}")
# playerContent: parse=0 直链 + header (UA + Referer)
```

## 4. 其他要点

- 封面 `cover_url` 有的直接是完整 URL、有的是 `/api/v3/public/zones/{zone}/media/assets/{asset_id}` 相对路径 → `_cover()` 统一 `url.startswith('http')` 判断
- 搜索返回 `data` 直接是 list（不是 `{items:[]}`）；theater/dramas 返回 `data.items`——**同一站点返回容器不一，取值时 `data if isinstance(data, list) else data.get('items', [])`**
- 全部分类（type_id='all'）用 rankings/hot 兜底（offset 翻页），genre 分类用 theater/dramas（cursor 翻页）
- 分类 slug：国产剧 `t-ucs0xp`、动漫 `t-k3onqj`、萝莉 `t-c2lbi7`、系统 `t-kv5ena`、创作者 `t-mqnyjd`、都市 `urban`、悬疑 `mystery` 等（主页"内容筛选"区 href 的 `?genre={slug}` 提取）
- 发文件用纯英文路径 `/opt/data/out/shorttv.py`（中文路径微信收不到）

# 短剧站 API 源（第二站）：西瓜短剧 xiguaduanju.com

> 2026-08-24 实战。与绮梦短剧（shorttv.online，见 `短剧站API-绮梦短剧.md`）**同一 SaaS 架构**，但 API 基址/header/播放接口不同。成品 `templates/shorttv.py` 同目录交付过，本笔记记 API 差异 + 解锁链路。

## API 概况

- **基址**：`https://api.djjz.xss16.com/api/v3`（Vite SPA 的 `config.js` 里 `window.__ENV__.VITE_API_BASE`）
- **⚠️ 必带 `X-Zone: XIGUADUANJU` header**（不是 `Zone`/`X-Zone` 大小写变体，就是 `X-Zone`；缺失报 `missing zone header`，加了但无 token 报 401）。ZONE 值也在 config.js（`VITE_DEFAULT_ZONE`）
- Referer: `https://xiguaduanju.com/`，UA 用手机安卓
- SPA 探测法：首页 HTML 几百字节 + `<script src="/assets/index-*.js">` + `/config.js` → API 端点全在 config.js，接口路径在 index.js 里搜 `P(\`/...\`)` 模式（P 是 fetch 封装）

## 核心接口（与绮梦的对应关系）

| 功能 | 西瓜 | 绮梦 |
|------|------|------|
| 首页 | `GET /feed` → `{items:[{drama:{...}}], nextCursor}` | `GET /webpc/home` |
| 列表/分类 | `GET /dramas?sort=weight\|new\|hot\|rating&contentKind=SHORT_DRAMA\|SERIES\|MOVIE\|ANIME&categorySlug={slug}&region=&year=&limit=24&cursor=` | `GET /feed/items?genre={slug}&sort_by=` |
| 搜索 | `GET /search?q={kw}&limit=` → `data` 是 **list**（非 items） | `GET /search?q=` |
| 详情 | `GET /dramas/{id}` → episodes[]（index/isFree/locked） | `GET /public/dramas/{id}` |
| 播放 | `GET /dramas/{id}/watch?index={n}&adultConfirmed=1` → `episode.hlsUrl` | `GET /me/dramas/{id}/episodes/{n}/playback` → `episode.playback_url` |
| 游客 | `POST /auth/guest` `{device_id}` | `POST /api/v3/auth/guest` `{device_id}` |
| 成人确认 | `POST /secret/confirmAge` + `POST /secret/confirmAdultOnly`（+ 播放时 `adultConfirmed=1`） | `POST /me/adult-confirmations` |

## ⚠️ 播放参数名坑

- `?episode=3` **被忽略**（永远返回第 1 集）；`?index=3` 才生效
- **敏感剧（SENSITIVE）解锁三件套**：①游客注册拿 Bearer token ②`/secret/confirmAge` ③**watch 请求必须带 `adultConfirmed=1`**（query 参数，来自 JS `Qu()` 函数 `{index, surface, adultConfirmed: i?'1':void 0}`）——三个缺一不可，否则敏感剧 hlsUrl 永远 None
- 锁定集（index > freeEpisodes）：`locked=True`、hlsUrl 无、`unlockPriceCoins=80`（coins 充值付费墙，游客 0 币，**无解，别浪费时间**）
- 敏感剧搜不到/详情 404 是站点过滤，正常现象

## 免费额度（用户选它的原因）

- 热剧免费 3~6 集（freeEpisodes 字段），feed 推荐里大量 **freeEpisodes=9999（全免费）**
- 比绮梦（仅 1 集免费）多得多 → 用户原话"西瓜短剧是收费的还是免费的？如果是免费的，你直接写西瓜短剧吧"——**用户偏好免费集多的源**

## 列表/详情结构

- 列表项（/dramas、/feed 的 drama 字段）：`id/title/cover/poster/freeEpisodes/totalEpisodes/contentKind/categories[]/tags[]`
- 详情 episodes：`{id, index, title, isFree, locked}`
- 播放 URL：`cdn.shorttv.online/lsj/hls/.../master.m3u8` 或 `uploads/direct/.../video.mp4`（mp4 直链 31MB 实测 200 可播）

## ⚠️ 选集慢 = 串行请求播放地址 → 必须并发

用户反馈"剧集开始播放的特别慢，要加载十几秒钟才出来选集"——detailContent 对每集串行调 watch 接口（1集1s，9集9s+）。**修复：`concurrent.futures.ThreadPoolExecutor(max_workers=10)` 并发请求所有免费集**，结果按 index 排序（`futs = {ex.submit(fn, ep): ep}` 保留映射）。实测 9 集 **10.7s → 2.0s**。

## 探测路径速记（下次同架构站直接复用）

1. 首页 HTML 小 + config.js 有 `VITE_API_BASE`/`VITE_DEFAULT_ZONE` → 同 SaaS
2. index.js 搜 `P(\`/...\`)` 拿全部接口路径；`client-*.js` 里看 header 注入（`X-Zone`）
3. 播放函数定义在 index.js（如 `Qu = P(\`/dramas/${id}/watch\`, {query:{index, surface, adultConfirmed}})`）——**参数名从 JS 函数签名抄，不要猜**
4. guest 注册 → confirm → 带参请求，三步验证敏感剧

# 绮梦短剧分类接口修正：theater/dramas genre 参数失效 → feed/items（2026-08-24）

**触发**：shorttv.py v1 交付后用户反馈"分类都是错误的，每个标签页下面内容完全相同"。

## 根因

`theater/dramas?genre={slug}` 的 **genre 参数被服务端忽略**——`?genre=t-ucs0xp` / `?genre=t-k3onqj` / `?genre=urban` / 不带 genre **全部返回同一份默认推荐列表**（首条都是"淫魔重生之情欲江山"）。对照实验（2026-08-24 实测）：

```
theater/dramas?genre=t-ucs0xp&limit=10  → 淫魔重生之情欲江山/豪门宠妻/夫妻游戏...
theater/dramas?genre=t-k3onqj&limit=10  → 淫魔重生之情欲江山/豪门宠妻/夫妻游戏...（相同！）
theater/dramas?genre=urban&limit=10     → 淫魔重生之情欲江山/豪门宠妻/夫妻游戏...（相同！）
```

**判定法**：先 GET 两个不同 genre + 无 genre，对比首条 id 是否不同；相同 = genre 参数无效，换接口。

## 正确接口：feed/items

```
GET /api/v3/public/feed/items?genre={slug}&limit=20&cursor={cur}
```

不同 genre 返回**完全不同**内容（t-ucs0xp/t-k3onqj/urban 三组 id 两两不重叠）。同站还有 `/api/v3/public/feed/initial`（单条 feed 流，不适合列表源）、`/api/v3/public/webpc/home`（首页 hot/updates）。

## feed/items 关键细节（全踩过）

| 项 | 值 | 踩坑说明 |
|----|----|---------|
| **item 结构** | `{id, drama:{...}, trailer_url}` | 剧信息（title/cover_url/total_episodes）在 **`drama` 字段**，不在顶层！`_card()` 必须先 `if 'drama' in item: item = item['drama']`，否则标题全空 |
| **limit 上限** | **20** | limit=30 → 400（theater/dramas 上限 30、rankings 上限 50，各端点不同） |
| **翻页** | **cursor**（`next_cursor`） | `offset` 参数无效（offset=20 返回 0 条）；`page` 参数也无效（p1/p2 相同） |
| **排序筛选** | **`sort_by=`** | `sort=new` 返回 0 条；`sort_by=hot|new|newest|popular|latest|follow` 全部有效且内容不同（热度/最新/人气/最新发布/追剧榜）。filters 定义 `{'key':'排序','name':'排序','value':[{'v':'hot','n':'热度优先'},...]}`，categoryContent 里 `for d in [filter, extend]: if isinstance(d, dict) and d.get('排序')` 读取 |

## 分类 slug 来源

主页"内容筛选"区 href 的 `?genre={slug}`：国产剧 `t-ucs0xp`、动漫 `t-k3onqj`、萝莉 `t-c2lbi7`、系统 `t-kv5ena`、创作者 `t-mqnyjd`、都市 `urban`、悬疑 `mystery`、犯罪 `crime`、喜剧 `comedy`、家庭 `family`、青春 `youth`、校园 `campus`。

## 通用教训（写 SPA 站 py 源时）

1. **"分类内容全相同" 第一嫌疑 = 筛选参数被服务端忽略**，不是解析 bug——先对照不同参数值返回的 id 列表
2. **同站不同端点参数语义可能完全不一致**：theater/dramas 与 feed/items 都叫 genre，一个失效一个生效；翻页机制也是 cursor/offset 混用，逐端点实测
3. **付费短剧站**：`episode.locked=True` 无 playback_url（付费墙）；`sensitivity=SENSITIVE` 剧游客无播放链接（需登录成人确认）——这些在 detailContent 里 `continue` 跳过即可，不是 bug

## 本 session 踩坑（都修好了）

1. **集数在视频页不在详情页**：`/detail/xxx/` 页面没有 `hg-play__episodes`（我第一次只查详情页，播放走了兜底）→ 必须请求视频页

4. **categoryContent 的 pg 是字符串**：`pg + 1` 报 TypeError（can only concatenate str）→ 函数开头 `pg = int(pg) if str(pg).isdigit() else 1`（玩物社区同样踩过）

6. **排行榜卡片标题**：`hg-rank-item` 用 `data-track-title`，简介 `hg-rank-item__desc`，热度 `hg-rank-metric-value`
7. **专题 folder**：一级 `vod_tag="folder"` + vod_id=`/topics/xxx/`；detailContent 遇 `/topics/` 返回空 list 让播放器走 categoryContent
