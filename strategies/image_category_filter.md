# 图片站二级分类筛选模式 v9.5

## 适用条件
图片、写真、壁纸或图集站需要一级分类与二级分类，且目标客户端实测不支持图片项目的 folder 路由。

## 规则
- 一级分类进入 `class`，父级 `type_id` 使用稳定的普通字符串，不使用 `folder:` 前缀。
- 二级分类放入 `filters[type_id]`，结构必须是过滤器列表：`[{'key': 'cateId', 'name': '子分类', 'value': [...] }]`。
- 过滤器不要添加未经实测的“全部”选项。父级未携带筛选值时，默认使用第一个真实子分类。
- `categoryContent` 同时接受 dict、JSON 字符串、空值，提取 `cateId` 后构造真实路径。
- 图片懒加载至少按 `data-bg`、`data-src`、`data-original`、`src` 顺序提取，列表失败时再使用结构性兜底。

## 适配要求
folder 是否可用必须以目标客户端和站点实测为准；不同客户端可能有不同能力，不能把单一客户端结论推广到全部环境。分类、筛选路径和分页参数均需实测。
